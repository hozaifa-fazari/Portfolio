---

## 🌟 Key Features & UX Innovations

- **Narrative Case Study Architecture:** Shifts from static image dumps to a structured storytelling framework: `[Context ➔ The Challenge ➔ Creative & Editing Solution ➔ Final Impact]`.
- **Dynamic Category Filtering:** Categorized navigation dividing work into Commercial Ads, Corporate/Events, Reels & Personal Branding, YouTube Content, Branding & Motion, Commercial Culinary Photography, and Editorial Portraiture.
- **Micro-Interactions & Hover Loops:** Custom CSS/JS implementation triggering HTML5 video loops on card hovers (Before/After design transformations, motion graphics previews).
- **Dark Mode Agency Aesthetic:** Built with a technical timecode rail, Marigold (`#F0A32E`) visual dividers, and clean grid geometry.
- **Responsive Media & Auto-Matte Framing:** CSS `object-fit` and custom aspect ratios ensuring zero visual clipping or irregular borders across all device screens.
- **Full-Screen Video Lightbox Modal:** Instant video player overlays linked to Drive/Vimeo masters for full-fidelity viewing.
